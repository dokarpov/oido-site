## Evidence grading
- Implemented: current tested code, not necessarily deployed or adopted.
- CI simulation: synthetic accounts, browser states, no real user proof.
- Founder reported: lead conversations without documentary verification.
- Pilot target: prospective future threshold, not completed.
- Projection: model conditional on assumptions, not historical financial result.
- Verified commercial result: signed and collected money, verified usage and directly observed costs.

## Disclosure and controls
The public GitHub Pages site is a promotional/browser demo, not the D1-backed pilot runtime. The pilot code is staged in an unmerged PR and requires a Cloudflare Pages project, D1 binding, operator secret, privacy and abuse controls. Even after a successful technical CI test it is not yet a validated paying merchant product.

Before telling investors that Oído has real orders, tipping, paid conversion, GMV, operational automation, tax-ready reports or retention, attach a source with date, owner, numerator/denominator and methodology. No testimonials without consent.

## Release gate
G0 privacy, staff coverage, security + D1 configuration → G1 1–3 real supervised merchants → G2 8–15 activated evidence cohort and longitudinal data → G3 paid continuations and sustainable support. A CI pass is a technical prerequisite, never business proof.
